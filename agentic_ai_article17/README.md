# Article 17 — Agent observability demo
Python 3.9+, standard library only. Run `python -m unittest -v` and `python demo.py`. The latter overwrites traces.jsonl. Two deterministic scenarios use fictional source IDs D01 (stale) and D04 (decisive). Validation is a fixture checking discovery, not semantic correctness or citation accuracy. The stale path times out on attempt 2 and retries on attempt 3. Both runs complete, only one validates. Durations are actual local timings, not provider latency. This custom JSONL schema is not OTLP and does not implement OpenTelemetry, real inference, distributed propagation, cost accounting or production export. The article separately illustrates OpenTelemetry API instrumentation.
